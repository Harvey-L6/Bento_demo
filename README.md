# Bento_demo｜排班與便當訂購統計工具

以 **Google Sheets + Google Apps Script** 實作的行政作業自動化作品：從行事曆與員工主檔整理當日出勤名單，套用請假／加班資料，再統計便當與牛奶數量，產生可複製的訂購訊息。

此 repository 用於作品集的程式碼展示，保留原型實作。未附真實員工資料、業務試算表或 Google 帳號憑證；若要試跑，需自行建立符合下列格式的測試試算表。

## 功能與流程

1. **帶入出勤名單**：依指定日期、上班日設定與 A／B 輪班班次篩選員工。
2. **處理請假與加班**：依員工主檔補齊編號或姓名，檢查部分重複與出勤衝突，標記請假並追加加班人員。
3. **分廠統計**：計算一廠、二廠的葷食、葷食不飯、素食、素食不飯及牛奶，加入外部訂購數量。
4. **產生訂購文字**：將便當與牛奶訊息寫入儲存格，供使用者複製到 LINE 等通訊工具。
5. **一鍵執行**：依序執行上述流程；某步驟回傳失敗或發生例外時停止後續步驟。

「一鍵全自動」由使用者在試算表選單啟動，執行時仍會顯示提示視窗。本專案沒有設定定時執行，也沒有串接 LINE 發送 API。

## 技術與檔案

- Google Sheets：輸入、操作介面與結果呈現。
- Google Apps Script：V8 JavaScript，使用 SpreadsheetApp、HtmlService 等內建服務。
- 專案時區：Asia/Taipei。
- 不需另填 API key；首次操作需完成 Google Apps Script 授權。

| 檔案 | 職責 |
| --- | --- |
| `按鈕.gs` | 透過 `onOpen()` 建立試算表自訂選單 |
| `計算出勤者.gs` | 日期選擇視窗、行事曆比對與當日出勤篩選 |
| `請假、加班.gs` | 請假／加班輸入檢查、資料補齊與名單更新 |
| `計算便當數量.gs` | 員工餐點條件判斷、分廠及外部數量加總 |
| `訂購訊息.gs` | 產生便當與牛奶訂購訊息 |
| `全自動.gs` | 串接四個核心步驟 |
| `appsscript.json` | V8、時區與例外記錄設定 |

## 試算表結構

建立四個工作表，名稱必須與程式一致：

| 工作表 | 標題／資料位置 | 用途 |
| --- | --- | --- |
| `主檔` | 第 1 列標題，第 2 列起資料 | 員工編號、姓名、班別、廠別與餐點偏好 |
| `行事曆` | 第 1 列標題，第 2 列起資料 | 每日是否上班、當日輪班班次 |
| `計算` | B1 為日期，第 2 列標題，第 3 列起員工名單 | 出勤結果、分廠統計與訊息輸出 |
| `請假/加班` | 第 3 列起，固定讀取 A:D | 當次要處理的請假／加班名單 |

### 主檔

建議使用以下標題，與「計算」中的員工欄位同名：

`員工編號`、`員工姓名`、`班別`、`廠別`、`夜班`、`素食`、`不要飯`、`不要牛奶`。

| 欄位 | 規則 |
| --- | --- |
| 員工編號 | 使用唯一編號；可設為純文字以保留前導零 |
| 班別 | `0` 為一般班；`A`、`B` 為輪班 |
| 廠別 | `1` 或 `2` |
| 夜班／素食／不要飯／不要牛奶 | 肯定值用 `Y`、`是` 或布林值 `TRUE`；否定可留空 |

以下僅為虛構測試資料：

| 員工編號 | 員工姓名 | 班別 | 廠別 | 夜班 | 素食 | 不要飯 | 不要牛奶 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| DEMO001 | 測試人員甲 | 0 | 1 | | | | |
| DEMO002 | 測試人員乙 | A | 2 | | Y | | |
| DEMO003 | 測試人員丙 | B | 1 | Y | | | Y |

### 行事曆

必要標題為 `日期`、`是否為上班日`、`輪班班次`。

- 日期需為 Google Sheets 的日期值，而非純文字。
- `是否為上班日` 必須填 `是`，一般班才會列入出勤。
- A／B 班依 `輪班班次` 比對出勤，不受一般班上班日條件限制。

### 計算

**B1** 放目標日期，並設為日期格式。

員工區由 A 欄開始，第 2 列放與主檔同名的欄位，最後加入 `請假`、`加班`；`加班` 應位於員工區最後一欄，右側再安排統計與訊息區。範例可將員工區放在 A:J，K:M 留空。

統計區可依原始設計安排在 N:S，第 2 列依序填：

| 欄 | N | O | P | Q | R | S |
| --- | --- | --- | --- | --- | --- | --- |
| 標題 | 葷 | 葷-不飯 | 素 | 素-不飯 | 便當合計 | 牛奶 |

統計程式依標題找欄位，但以下列號固定：

| 列 | 用途 |
| --- | --- |
| 3 | 一廠統計 |
| 4 | 二廠統計 |
| 5 | 一廠＋二廠初始加總 |
| 6 | 外部訂購，歸入一廠；手動輸入各餐別與牛奶，便當合計由程式計算 |
| 7 | 初始加總＋外部訂購總數 |

訊息相關位置固定如下：

| 儲存格 | 用途 |
| --- | --- |
| N11／O11 | 一廠額外白飯／鹹湯數量 |
| N12／O12 | 二廠額外白飯／鹹湯數量 |
| N15 | 便當單價 |
| R11 | 便當訂購訊息輸出 |
| R12 | 牛奶訂購訊息輸出 |

便當統計排除請假與夜班人員；牛奶統計排除請假與標記「不要牛奶」的人員，夜班人員仍可計入牛奶。其他廠別不列入一廠／二廠統計。

### 請假/加班

從第 3 列起填寫以下固定位置：

| 欄 | 內容 |
| --- | --- |
| A | 請假員工編號 |
| B | 請假員工姓名 |
| C | 加班員工編號 |
| D | 加班員工姓名 |

可只填編號或姓名，由程式依主檔補齊另一欄。若兩欄皆填，請自行確認兩者屬於同一人。此工作表不含日期篩選，執行前請整理成當次目標日期的名單。

## 安裝與操作

1. 建立 Google Sheets 測試檔，依上述結構建立四個工作表並填入虛構資料。
2. 在試算表中選擇 **擴充功能 → Apps Script**，建立綁定該試算表的專案。
3. 將本 repository 的六個 `.gs` 檔加入專案。
4. 在 Apps Script 專案設定開啟顯示 `appsscript.json`，套用 repository 的 manifest；試算表時區也建議設為台北。
5. 儲存後重新開啟試算表，確認出現 **🍱 排班與便當管理系統** 選單。
6. 在「計算」B1 設定日期，準備請假／加班、外部餐點、附餐與單價。
7. 點選 **🔥 一鍵全自動：刷新今日便當**，依 Google 提示完成必要授權；也可依選單 1 → 2 → 3 → 4 分步操作。
8. 檢查統計及 R11／R12 的文字，確認後自行複製發送。

重新處理同一天時，請先重新帶入出勤名單，再依序處理請假／加班及統計，避免重複追加造成衝突。

## 展示版本說明

本版本主要展示試算表工作流程、欄位對應、條件統計及訊息生成。repository 未提供可直接複製的試算表範本；僅下載程式碼並不會自動建立工作表。

程式保留原型行為：訂購訊息目前未包含「素-不飯」，可能與完整統計總數不同；請假／加班處理會將讀取範圍寫回數值，測試表的相關範圍請使用靜態資料。流程停止時不會回復先前已完成的寫入。此版本為流程原型；試跑時請核對各餐別統計與訂購訊息，正式使用前需完成相關修正與驗證。
